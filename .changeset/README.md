# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works
with multi-package repos (also known as monorepos). Whether you've ran into this by mistake, or you've come here
intentionally, let's explain what this is and why it's here.

## What's a changeset?

A changeset is a piece of information about changes made in a branch or commit. It holds three bits of information:

- What packages we changed
- What version update type should happen for those packages (major, minor, or patch)
- A summary of the changes made

## How do I use this?

Add a changeset with `pnpm changeset` or `npx changeset`.

Commit the changeset file along with your changes.

When you're ready to release, run `pnpm version-packages` to bump versions and then `pnpm release` to publish.
